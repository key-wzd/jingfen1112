# AI Lab 二次开发记录

## 本轮已完成

### 运行隔离

- 副本目录：`apps/web-naive-ai`
- 前端端口：5892
- API 端口：3004
- 数据库：`techcompare_internal_ai`
- 源项目：`apps/web-naive-polished`

### 实验工作台

新增 `/lab` 页面，提供：

- 当前数据质量分数
- 品类记录数和缺测率
- 统计异常复核队列
- 最近导入批次
- 直接进入对应功耗分析

### 数据与服务

- 新增 `dataset_manifest` 表，记录导入批次、文件哈希、品类和记录数。
- 新增 `GET /api/lab/summary`，由服务端计算质量和异常摘要。
- 新增 `POST /api/ai/ask`，目前是只读、本地规则分析，不调用外部模型。
- 分析助手允许普通账号读取，但不能修改数据。

## 设计边界

当前分析助手刻意不执行 SQL、不导入文件、不删除记录、不修改图表配置。真实模型接入时，应继续沿用“服务端授权工具查询 → 模型解释 → 返回证据引用”的流程。

## 下一阶段

1. 增加测试批次、固件、系统、环境、仪器和操作者实体。
2. 为每条测量记录保存来源文件、原始单元格、单位和转换过程。
3. 增加阈值、重复性、异常复核和评论审批。
4. 生成带数据版本和证据引用的评审报告。
5. 评测真实模型的准确率、引用完整性、延迟和成本后再接入模型服务。
