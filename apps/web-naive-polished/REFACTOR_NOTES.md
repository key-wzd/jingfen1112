# 内部功耗分析工作台 · 本轮改造说明

日期：2026-10-20

## 定位与范围

网站用于内部专业人员查看、核对和可视化测试数据。页面用语已统一为“测试对象、设备参数、功耗记录、场景对比”，移除了选购、推荐和购买相关宣传文案。

本轮业务源代码修改位于 apps/web-naive-polished。原 web-naive 的源文件与资源以 review/original-manifest.json 的 SHA-256 基线做最终核对。

## 轮播图保留要求：待提供源位置

在当前原目录、副本、apps 下的源文件，以及首页可见 Git 历史中，未找到轮播组件或轮播图片。当前可见首页只有静态首屏。已询问原轮播所在的文件路径、目录或页面地址。

本轮没有新增替代轮播，也没有删除任何既有轮播图片。首屏只基于当前可见结构调整文案与统计。原轮播的恢复/逐张核对尚未完成，不能把当前静态首屏视为轮播需求的交付。取得源位置后应保留全部原图、顺序与切换行为，再进行外围样式融合。

## 首页与图标

- 手机图标：机身、屏幕、听筒和底部横条。
- 鼠标图标：鼠标轮廓、左右按键分界和滚轮。
- 键盘图标：具体键帽与空格键；遥控器图标：电源键、方向圆环和按键。
- 各品类入口直接进入功耗分析，设备参数对照保留为辅助入口。
- 首页数量来自服务端 COUNT 汇总；取消固定 +12%、装饰性趋势数据与常亮的“实时”状态。
- 显示获取中、已获取、连接失败、空数据及重试。最近获取时间代表本次请求完成时间，不冒充测量更新时间。
- 调整正文与数据字号，提高对比度；保留系统缩放和减少动画偏好。

## 功耗分析

- 搜索品牌/型号，选择筛选结果、清空选择，支持多个对象。
- 保留原配置的 line / summary 分组与 null 占位语义。
- 保留原始导入表头，可展开核对。
- 每行图例独立显隐对象；每个图表可展开原始数值。
- 0 保留为 0；空值、无效字符串、非有限数值按缺测处理，不再转换为 0。
- 场景单位单独标注，不从另一个场景借用单位；单位不明时明确提示。
- 删除将跨指标加总排序直接称为“测试结论”的逻辑。已有导入结论显示为“导入备注”。
- 折线保留原测量点，不使用平滑曲线推测中间趋势。
- 当前支持分组柱状图、横向柱状图、折线图；其他配置会明确说明采用分组柱状图展示，不能称为原生雷达图/饼图支持。
- 支持导出当前选中对象的 CSV，包含品类、对象、场景、指标、数值、单位和数据状态。
- ResizeObserver 处理窗口尺寸变化；离开页面或清空后释放图表实例。
- 品牌与型号共同匹配；同品牌同型号的多条源记录保留并显示记录编号，不自动猜测匹配。

## 身份、服务与数据隔离

- 登录由服务端校验，并签发随机会话令牌；会话有效期为 8 小时，退出后服务端立即撤销。
- 写操作由服务端检查管理员角色，前端隐藏按钮不是权限边界。
- 生产模式必须配置两个账户密码。前端调试账号提示仅在开发构建显示。
- 副本前端默认 5890，API 默认 3002，数据库默认 techcompare_internal_copy。
- 同源代理处理 /api 与 /uploads，生产部署也需配置相应反向代理。
- 禁止此副本使用原 phone_compare 库。数据库密码保存在 server/.env.local，已忽略提交，日志不再输出密码。
- 首次使用独立数据库时加载副本 public/gh.xlsx；没有自动复制或修改原数据库。独立环境数据不会自动跟随原库变化。
- 去掉模板中的第三方统计脚本。

## Excel 导入

1. 选择或拖入不超过 20 MB 的 xls/xlsx 文件。
2. 校验工作表、字段、品牌型号和数值，显示每张表的记录数。
3. 同名记录原样保留并在预览提示；不擅自去重。
4. 预览令牌绑定当前登录会话、文件哈希和有效期；换文件后必须重新校验。
5. 新数据写入独立暂存表，全部成功后通过事务切换元数据。
6. 未包含的数据类型不被删除；旧数据表及恢复清单保留。
7. 写入或校验失败时不将新表切换为当前数据。

恢复清单位于 server/backups。查看恢复计划：

```powershell
cd server
node restore-import.mjs import-实际批次.json
```

核对目标后附加 --apply 才执行恢复。此脚本校验数据库名，仅恢复清单涉及品类的元数据指向。旧表不自动清理；后续应按组织的数据保留策略维护。已有历史数据若在旧导入流程中被错误写成 0，本次修改不能反推原缺失值，需重新导入原始文件。

## 启动与验证

在副本目录执行：

```powershell
pnpm start
```

或双击 start.bat。数据库连接配置见 server/.env.example；server/.env.local 中填写实际配置。现有本地调试账号沿用 user/user123、admin/admin123。生产部署应设置 NODE_ENV=production、TC_ADMIN_PASSWORD、TC_ANALYST_PASSWORD；此轮没有接入企业 SSO。

```powershell
pnpm typecheck
pnpm build
node --test tests/measurements.test.mjs
node tests/api.integration.mjs
node tests/browser.integration.mjs
```

后两个集成测试需要副本服务启动。API 集成测试明确限制成功导入到 3002 的隔离实例，会在该实例导入随附模板；不能对原服务运行。测试使用 Node 24。浏览器脚本使用已安装的 Microsoft Edge。

验证记录保存在 review/api-test-results.json、review/browser-test-results.json；页面截图也位于 review。dist.zip 只包含前端生产资源，不包含 API 或数据库，不应直接作为完整系统交付包。



## 本轮追加功能

- 在 `src/layouts/components/PowerCarousel.vue` 新增内部功耗分析轮播组件，并嵌入首页。组件支持自动播放、上一张/下一张、指标点切换、暂停、键盘/ARIA 标识和减少动画偏好。当前未找到原项目的轮播源，因此没有删除或替换既有轮播资源；取得原轮播路径后需继续核对资源顺序。
